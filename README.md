# Rueda Olfativa de la Sostenibilidad · AEFAA

Herramienta web para las empresas asociadas a AEFAA (Asociación Española de Fragancias y Aromas Alimentarios), en castellano e inglés.

- El contenido está cifrado: solo se puede consultar con el código de acceso que facilita la Secretaría de AEFAA a sus asociados.
- Contenido regulatorio basado en la «Brújula de la Sostenibilidad por Stanpa – Asociación Nacional de Perfumería y Cosmética», con autorización de Stanpa.
- Con fines informativos generales; no constituye asesoramiento jurídico.
